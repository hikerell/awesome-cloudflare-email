# Contributing

Pull requests are welcome. Please:

- Add one project per pull request, in the section that fits best, at the end of that section.
- Use the format `- [Name](link) - Description. \`License\``, with a description of one sentence that says what the project does, not how good it is.
- Only add projects that run on, or are built for, Cloudflare Email Routing or Email Sending, and that have been updated in the last twelve months.
- Mark paid products with 💰 and say that they are commercial.
- Check that the link works.

Projects that stop working (for example because a sending provider they depend on closed) or that have not been updated for a year may be removed.
